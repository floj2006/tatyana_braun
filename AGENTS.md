# Правила проекта

Сайт ведущей праздников Татьяны Браун. React 19 + Vite, без сервера, деплой на Vercel.

## Контент
- Весь контент в `src/content/site.js`. Компоненты контент не хардкодят.
- Факты публикуются только подтверждёнными: город, цены, длительность, DJ/звук/оборудование,
  предоплата и возвраты, отзывы, мероприятия, контакты, количество праздников, награды.
  Не придумывать их, даже «для примера».
- Пустое значение или пустой массив скрывает раздел и пункт меню. Заглушки на сайте не публикуются.
- Тексты о стиле, форматах и подготовке написаны по образу Татьяны по просьбе заказчика.
  Что нужно получить от Татьяны — в `QUESTIONS.md`.
- Тон: конкретно, без штампов («незабываемый», «индивидуальный подход», «атмосфера»),
  без конструкций «не просто X, а Y».

## Контакт
- Основной путь — личные сообщения VK. Форма только собирает текст и ничего не отправляет.
  Не писать «заявка отправлена». Не полагаться на предзаполнение сообщения в VK.
- Сбор персональных данных или аналитика требуют политики обработки ПДн и согласия (152-ФЗ).

## Безопасность
- CSP без `unsafe-inline`: никаких inline-скриптов и атрибутов `style`, `dangerouslySetInnerHTML`.
- Внешние ссылки только через `safeUrl` (https + белый список хостов) и с `rel="noopener noreferrer"`.

## Проверки перед коммитом
`npm run check` — ESLint, тесты (vitest) и production-сборка с пререндером.
