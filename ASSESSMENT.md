# Состояние проекта

## Что на сайте
Первый экран (имя, позиционирование, фото, «Узнать, свободна ли дата», быстрый выбор повода) →
[видео] → «Как Татьяна ведёт» → форматы (вся строка кликабельна, выбор переносится в форму) →
[мероприятия] → [отзывы] → подготовка → условия и стоимость → вопросы → обращение.
В квадратных скобках — разделы, которые появятся, когда будут материалы.

Скрыты до появления подтверждённых материалов: город, видео, реальные мероприятия, отзывы,
длительность, DJ/звук/оборудование. Код разделов готов (`Events`, `Reviews`, поля `TERMS`, `SITE.city`, `SITE.video`).

## Путь обращения
Прямой контакт во VK. Форма собирает формат, дату (или «даты пока нет»), город, число гостей и комментарий;
имя не спрашивается. Одна кнопка «Скопировать текст и открыть VK»: текст копируется синхронно в момент нажатия
и открывается страница Татьяны, посетителю остаётся вставить текст. Если браузер запретил копирование,
VK не открывается сам: текст выделяется для ручного копирования, рядом кнопки «Попробовать ещё раз» и «Открыть VK».
Текст можно посмотреть заранее. Предзаполнение сообщения в VK не используется: оно не подтверждено.

## Технически
- Пререндер HTML при сборке; Preact вместо React (JS 76 → 17 КБ gzip).
- Фото героя: AVIF с запасным webp (480/800/1120), размеры заданы, preload и `fetchpriority=high`.
- Шрифты: 4 файла woff2 (кириллица и латиница) вместо 22, кириллические предзагружаются.
- canonical, Open Graph с картинкой 1200×630, favicon, apple-touch-icon, robots.txt, sitemap.xml,
  JSON-LD `Person` с перечнем услуг-форматов; без цен и географии, пока они не подтверждены.
- CSP без `unsafe-inline`, HSTS, `X-Frame-Options`, `nosniff`, `Referrer-Policy`, `Permissions-Policy`.
- Шрифты Prata и Onest хостятся локально. Аналитики нет.
- Анимации: появление разделов и первого экрана, отклик кнопок; при `prefers-reduced-motion` отключены.
