# Состояние проекта

## Что на сайте
Первый экран (имя, позиционирование, фото, «Узнать, свободна ли дата», VK) → «Как Татьяна ведёт» →
форматы (выбор переносится в форму) → подготовка → условия и стоимость → вопросы → обращение.

Скрыты до появления подтверждённых материалов: город, видео, реальные мероприятия, отзывы,
длительность, DJ/звук/оборудование. Код разделов готов (`Events`, `Reviews`, поля `TERMS`, `SITE.city`, `SITE.video`).

## Путь обращения
Прямой контакт во VK — основное действие. Форма собирает формат, дату (или «даты пока нет»), город,
число гостей и комментарий. Имя не спрашивается: VK и так его покажет. Форма ничего не отправляет:
показывает готовый текст, кнопку «Скопировать текст» и кнопку «Открыть VK». Если Clipboard API отказал,
текст выделяется и показывается инструкция для ручного копирования. Предзаполнение сообщения в VK не используется.

## Технически
- Пререндер HTML при сборке; адаптивные webp (480/800/1120) с размерами и `fetchpriority=high` для героя.
- canonical, Open Graph с картинкой 1200×630, favicon, apple-touch-icon, robots.txt, sitemap.xml,
  JSON-LD `Person` только с подтверждёнными полями (имя, роль, фото, VK).
- CSP без `unsafe-inline`, HSTS, `X-Frame-Options`, `nosniff`, `Referrer-Policy`, `Permissions-Policy`.
- Шрифты Prata и Onest хостятся локально. Аналитики нет.
- Анимации: появление разделов и первого экрана, отклик кнопок; при `prefers-reduced-motion` отключены.
